# LiveLabs GTM

Use this to turn product truth into focused market communication. No generic SaaS positioning.

## Grounding

Load `references/gtm-template.md`. Use only product/customer/company context supplied by the user or explicitly available in the current request/workspace.

## Workflow

1. Pick one ICP and one trigger moment.
2. State the painful old workflow in customer language.
3. State the demo promise in falsifiable terms.
4. Explain why this team/product wins now, using real product capabilities.
5. Create the shortest path to proof: pilot, event, demo, or outbound sequence.

## Output

Use `references/gtm-template.md`. Keep copy concrete. Prefer precise customer language over abstract platform language unless the target is investor/fundraising.
