# Moat Lens

Ask these questions:

1. What is technically hard because the world is messy, not because the code is large?
2. What gets better with every event?
3. What data can only LiveLabs collect by operating the workflow?
4. What part of the stack must users trust during a live moment?
5. What can be demoed in two minutes that incumbents cannot copy without changing their architecture?
6. Where is LiveKit leverage, and where is LiveKit table stakes?
7. What should we avoid building because it will not compound?

For StreamBridge, prefer moats around orchestration, realtime reliability, operator workflow, AI-directed live decisions, and event-specific media/context graphs.
